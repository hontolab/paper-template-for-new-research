# CS論文の書き方ガイド（目次）

この資料は，主にSimon Peyton Jones *How to Write a Great Research Paper*，Jennifer Widom *Tips for Writing Technical Papers*，および『エリート的な文章の書き方』の内容を統合し，計算機科学分野の論文の標準的な書き方をまとめたものです．内容が長くなったため，以下の3つの文書に分割しています．

| 文書 | 内容 |
|---|---|
| [1-学術論文の書き方.md](1-学術論文の書き方.md) | 論文執筆の心構え，標準的な章立て，各章（Title / Abstract / Introduction / 本文 / Evaluation / Conclusion）に書くべき内容，Related Workの書き方，体裁の最終チェック，執筆プロセス |
| [2-文書の書き方.md](2-文書の書き方.md) | パラグラフライティング（1段落1トピック，トピックセンテンス，段落内・段落間の整合性），文レベルの規則，日本語文の構造的な悪癖，推敲 |
| [3-国際会議論文の傾向と対策.md](3-国際会議論文の傾向と対策.md) | CHI・CSCW・UIST・IUI・CHIIR・SIGIRの評価文化と，会議ごとに求められるもの |
