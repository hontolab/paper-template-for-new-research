# 論文執筆テンプレート

初めて論文を書く学生向けの LaTeX テンプレートです．
体裁は情報処理学会論文誌の投稿スタイルに近づけてあります．

まずこの `how-to-use-this-template.md` を読んで環境を整えてから，`how-to-use-latex/how-to-use-latex.pdf`（LaTeX の書き方の解説）に進んでください．

---

## 1. 環境の準備

執筆環境は Overleaf（オンライン）とローカル環境の2通りあります．
**特にこだわりがなければ Overleaf を使ってください．** 環境構築で悩む時間がなくなります．

### A. Overleaf を使う（推奨）

Overleaf はブラウザ上で LaTeX を執筆できるサービスです．
自分の PC/Mac の環境を汚さない，環境構築に苦労しないというメリットがあります．
一方，インターネットに接続していないと執筆作業ができないというデメリットがあります．

1. [Overleaf](https://ja.overleaf.com) にアクセスし，右上の「登録する」からアカウントを作成します．
   研究室のメンバーには，アカウントの作成に**研究室で発行した Google アカウント**を利用することを推奨します．
2. 指導教員がこのテンプレートから執筆用プロジェクトを作成し，あなたを招待します．あなたのアカウント名を指導教員に伝えてください．
   招待メールが届いたら，リンクを開いてプロジェクトに参加してください．
   （招待が届いていない場合は指導教員に連絡してください）
3. プロジェクトを開くと，画面左側のファイルブラウザに `paper.tex` や `section` フォルダが見えます．
4. 画面上部の緑色の「Recompile」ボタンを押すと，右側に PDF が表示されます．

Overleaf の設定で，以下の2点を確認してください（指導教員が設定済みのはずですが，
自分でプロジェクトを新規作成した場合は自分で設定する必要があります）．

- **メニュー → Compiler を「LaTeX」に設定**
  この文書は日本語組版のために pLaTeX を使います．
  同梱の `latexmkrc` に必要な設定が書いてあり，Overleaf はこれを読み込みます．
- **メニュー → Main document を `paper.tex` に設定**
  このプロジェクトには `paper.tex` と `how-to-use-latex/how-to-use-latex.tex` の
  2つの文書が入っているため，どちらをコンパイルするか指定する必要があります．

自分で zip をアップロードしてプロジェクトを作る場合は，
Overleaf のトップページで「New Project」→「Upload Project」から zip をそのままアップロードしてください．

### B. ローカル環境を使う

TeX Live などの LaTeX 環境をインストール済みの場合は，このフォルダで次を実行します．

```bash
latexmk paper.tex     # 論文をコンパイルして paper.pdf を作る
latexmk -C paper.tex  # 中間ファイルを掃除する
```

解説文書（`how-to-use-latex`）を作り直したい場合は，そのフォルダに移動してから実行します．

```bash
cd how-to-use-latex
latexmk how-to-use-latex.tex
```

`latexmkrc` に pLaTeX + pBibTeX + dvipdfmx の設定が書いてあるので，
上記のコマンド一発で BibTeX の実行や再コンパイルまで自動で行われます．

## 2. ファイル構成

| ファイル / フォルダ | 説明 |
| --- | --- |
| `paper.tex` | **論文本体．** タイトル・著者・概要・キーワードを書き，各章のファイルを読み込む |
| `section/` | 論文の各章．**執筆はこのフォルダの中のファイルを編集して行う** |
| `fig/` | 論文で使う図（PDF）を入れるフォルダ．最初は空 |
| `reference.bib` | 参考文献の情報を書くファイル |
| `how-to-use-latex/` | LaTeX の書き方の解説一式．**論文には含まれない．提出時はフォルダごと削除してよい** |
| `simplepaper.cls` | 論文のクラスファイル（後述の注意を参照）．**編集しないこと** |
| `ipsjsort.bst` | 参考文献リストの整形ルール．**編集しないこと** |
| `latexmkrc` | コンパイル方法の設定．**編集しないこと** |

`how-to-use-latex` フォルダの中身は次のとおりです．

| ファイル | 説明 |
| --- | --- |
| `how-to-use-latex.pdf` | **まずこれを読む．** LaTeX の書き方の解説 |
| `how-to-use-latex.tex` | 上の PDF のソース．PDF と見比べるために使う |
| `fig/sample.pdf`, `reference.bib` | 解説文書が使うサンプル（論文本体のものとは別のコピー） |
| `latexmkrc` | このフォルダ単体でコンパイルするための設定 |

`section` フォルダの中身は次のとおりです．
各ファイルの冒頭には，その章に何を書くべきかの解説がコメントで書かれています．
**まずそれを読んでから書き始めてください．**

| ファイル | 章 |
| --- | --- |
| `abstract.tex` | 概要（`paper.tex` から読み込まれる） |
| `introduction.tex` | 1章 はじめに |
| `related-works.tex` | 2章 関連研究 |
| `approach.tex` | 3章 提案手法 |
| `experiment.tex` | 4章 実験 |
| `results.tex` | 5章 結果 |
| `discussion.tex` | 6章 考察 |
| `conclusion.tex` | 7章 おわりに |
| `achievement.tex` | 研究業績（必要な場合のみ `paper.tex` から読み込む） |

章の構成は論文の内容によって変わります．
章を増やしたり減らしたりする場合は，`section` フォルダにファイルを追加・削除したうえで，
`paper.tex` の `\input{...}` の行を対応させてください．

## 3. 執筆の進め方

1. `paper.tex` の `\title{}`，`\author{}`，`\affiliation{}` を自分の情報に書き換える
2. `section/abstract.tex` に概要を書く
3. `section/` の各ファイルに本文を書く
4. 引用したい文献を `reference.bib` に追加し，本文中で `\cite{キー}` で引用する
5. こまめにコンパイルして，PDF の見た目を確認する

書き方の具体的なコマンド（見出し，段落，書体，箇条書き，図，表，参考文献の引用）は
**`how-to-use-latex/how-to-use-latex.pdf`** で解説しています．
PDF と，同じフォルダにあるそのソース `how-to-use-latex.tex` を見比べながら読むと理解しやすいはずです．

### 参考文献について

`reference.bib` に BibTeX 形式で文献情報を書きます．
形式を自分で作る必要はありません．
Google Scholar や ACM Digital Library には BibTeX 形式で書誌情報を出力する機能があるので，
それをコピーして貼り付けてください．

本文中で `\cite{}` していない文献は参考文献リストに載りません．

### 図について

図は jpeg や png（ラスタ画像）ではなく，**PDF（ベクタ画像）**を `fig/` に置いて使ってください．
拡大しても粗くならず，電子的に閲覧される論文に適しています．

## 4. 提出前のチェックリスト

- [ ] `\title{}`，`\author{}`，`\affiliation{}` が自分の情報になっているか
- [ ] コンパイル時にエラーや警告（`Undefined references` など）が出ていないか
- [ ] 本文中の図表参照（`図\ref{...}`）が `??` になっていないか
- [ ] `reference.bib` に書いた文献のうち，引用したものが参考文献リストに出ているか
- [ ] 図が PDF（ベクタ画像）になっているか
- [ ] テンプレートのサンプル文やコメントの消し忘れがないか
- [ ] ページ数の制限を満たしているか
- [ ] `how-to-use-latex` フォルダを提出物に含めていないか

## 5. クラスファイルについての注意

`simplepaper.cls` は，jarticle をもとにした学会非依存のシンプルなクラスファイルです．
体裁（文字の大きさや版面）は，情報処理学会論文誌の投稿スタイルに近い値に合わせてあります．

`paper.tex` の1行目のオプションを書き換えると，体裁を変えられます．

| 書き方 | 体裁 |
|---|---|
| `\documentclass{simplepaper}` | A4，2段組（既定） |
| `\documentclass[onecolumn]{simplepaper}` | 1段組．卒論・修論の下書き向け |
| `\documentclass[linenumber]{simplepaper}` | 行番号つき．添削してもらうとき用 |

オプションはカンマで併用できます（例：`[onecolumn,linenumber]`）．

**情報処理学会をはじめとする学会に実際に投稿する場合は，このクラスファイルではなく，
投稿先が配布している正規のスタイルファイルを使ってください．**
その場合は英文タイトルや英文概要なども必要になります．
