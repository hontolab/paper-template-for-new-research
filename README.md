# 研究を始めた時点から書き始める論文

## はじめに
学生の多くは「論文は研究がある程度進んで，実験結果も揃ってから書くもの」と思っていることでしょう．
その姿勢では**いつまで経っても論文を書き始められません**．
研究は常にon-goingなものですから，完成はありません．
また，研究の経験が少ない学生の場合，ある程度の結果を出すための時間，論文を完成させるのにかかる時間の見積もりがまだうまくできないため，**論文を書き始めるタイミングが遅く，結果的に文章としての完成度が低い論文ができあがってしまう**ことが往々にしてあります．

学生の皆さん，論文を書く目的を改めましょう．
卒業・修了するためには，卒業論文・修士論文を完成させる必要があります．
卒業論文・修士論文を完成させるためには，研究を行う必要があります．
しかし，論文を書く本当の目的は**研究を進めるため**です．
書くとは，頭の中にあるモヤモヤに言葉を与える作業です．
書くことによって，考えていることを構築，発見，認識できるのです．
**考えるために論文を書く．書きながら考え，研究を進める** —— そう考えて，今日から論文を書き始めましょう．


## 具体的に何をするか？
やまもと研究室に所属している学生は，Overleafのアカウントを作成した後，指導教員からOverleafプロジェクトへの招待状を入手しましょう．
指導教員は学生用に用意した論文執筆用のプロジェクトを作成してくれます．
プロジェクトには「研究を始めた時点から書き始める論文」を作成するためのLaTeXファイルが含まれています（ファイル構成はこのレポジトリと同じです）．

用意されたOverleafプロジェクトにアクセスできるようになりましたら，下記参考資料を参考に論文を書き進めていってください．

## 心構え
* 「研究を始めた時点から書き始める論文」は更新するのが前提です．研究を進めながら，内容や表現をブラッシュアップしていきます．初期の頃はクオリティが低いのは当然ですので，現時点で書けることを精一杯考えて書きましょう．
* 箇条書きだけの文章はできるだけ控えましょう．主語・述語をそなえる文を書くことによって，考えが不足している点，補強すべき点，曖昧な点が浮き彫りになります．
* 研究や論文は批判に曝されて育ちます．**毎回の個別ミーティングでは，執筆中の「研究を始めた時点から書き始める論文」を積極的に展開することをオススメします**．指導教員や研究室メンバーに読んでもらいましょう．定期的に見せることで，教員が添削する負荷も減ります．

## [重要] 生成AIの利用について
生成AIの普及によって，要件を伝えるだけで「それらしい文章」が手に入るようになりました．
日常的な文章であれば，それで済ませてよい場面もあるでしょう．
しかし，**学術論文の執筆に対しては，学会が生成AIの利用に厳しい基準を設けています**．

基準の詳細は，[AAAI](https://aaai.org/conference/aaai/aaai-26/main-technical-track-call/)[^1]，[ACL](https://www.aclweb.org/adminwiki/index.php/ACL_Policy_on_Publication_Ethics)，[ACM](https://www.acm.org/publications/policies/new-acm-policy-on-authorship)など学会によって異なりますが，著者に求められる点として次の2つは共通しています．

* **著者自身の知的貢献が残っていること**: 生成AIは著者になれません．論文の内容に対する責任は，すべて著者が負います．
* **論文執筆のどの箇所・どのプロセスに生成AIを利用したかを明らかにすること**: 論文中への明記を求める学会もあります．

文章執筆に慣れていない学生が，生成AIの力を借りたくなる気持ちは理解できます．
実際，多くの学会は，自分で書き上げた文章の品質を高めるための推敲・校正に生成AIを使うことは認めています．
アイデアを練る過程や，より良い論文に仕上げる過程を助けてもらう道具として，生成AIをうまく使ってください．
ただし，**知的貢献があなたではなく生成AIの側にあると見なされるような使い方は絶対にやめてください**．

誤った使い方をして，それが発覚した場合，あなただけでなく，共同執筆者や指導教員にまで実害が生じます．
判断に迷ったときは，自分で結論を出さず，必ず指導教員に相談してください．

[^1]: AAAI-26では，論文の草稿はもちろんのこと，論文中の段落を生成AIに一から作らせることも禁じられています（2026年8月時点）．

## このリポジトリの構成
```
paper.tex           論文本体（ここからsection以下を読み込む）
simplepaper.cls     本テンプレートのクラスファイル（変更しないこと）
ipsjsort.bst        参考文献のスタイルファイル（変更しないこと）
section/            各章の原稿
fig/                図
reference.bib       参考文献データベース
how-to-xx/          論文の書き方・LaTeXの使い方の参考資料
```

### クラスファイルのオプション
`paper.tex` の1行目を書き換えると，体裁を変えられます．

| 書き方 | 体裁 |
|---|---|
| `\documentclass{simplepaper}` | A4，2段組（既定） |
| `\documentclass[onecolumn]{simplepaper}` | 1段組．卒論・修論の下書き向け |
| `\documentclass[linenumber]{simplepaper}` | 行番号つき．添削してもらうとき用 |

オプションはカンマで併用できます（例：`[onecolumn,linenumber]`）．
